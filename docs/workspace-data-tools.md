# 文档资料、备份恢复、独立开发与连接向导

本文说明 **v1.1.5 本批的文档入库、工作资料备份恢复、独立开发目录与接入向导**，保留旧版使用方式和个人数据；不表示代码／标签已推送或 GitHub 正式 Release 已发布。发布工作流先创建 draft，待附件、版本、发行说明和 SHA-256 核验后再正式发布；发布前要求、待补充的验证结果及边界见 [v1.1.5 发行说明](releases/v1.1.5.md)。这些功能不会自动提交或推送项目代码。

## PDF／Word 入库

在 **设置 → 工作区与记忆 → 本地知识库 → 导入 PDF／Word** 选择文本型 PDF 或 DOCX。程序在本地受限 worker 中解析，展示页／段落内容；勾选所需单元，预览入库差异，再确认保存。可以创建新集合或把文本加入现有集合，现有集合其他文档保持原始字节和版本引用。

- PDF 使用真实物理页码；DOCX 使用段落／表格编号，不推算页码。
- 不支持扫描件 OCR、加密 PDF、旧 DOC、宏和嵌入对象。复杂版式不保证原样还原；预览应由用户核对。
- 不加载外部资源、不执行宏或脚本、不调用模型。原件最多 16 MiB；超出页数、解压、时间或输出上限会明确拒绝，不悄悄截断。
- 原件和来源映射在 `.sakura/documents/`，知识文本沿用现有集合预算。先存原件，后发布知识；失败时可能保留非检索原件。若文本已导入但集合登记失败，会明确返回批次 ID，刷新后登记该批次，勿重复导入。
- 解析器与资源随桌面包内嵌，不需要 Office 或 Python。worker 用于限时和资源限制，不是操作系统安全沙箱。

## 工作资料备份与恢复

在 **设置 → 工作区与记忆 → 工作资料备份与恢复** 选择会话、记忆、知识或任务，先预览清单再下载 `.sakura-backup`。

备份包含选中资料的依赖，例如会话附件、关联会话和知识历史。使用版本化 gzip/JSON 格式，逐文件记录 SHA-256；并非可直接执行的项目目录。默认最多 2,048 文件、64 MiB 内容、48 MiB 压缩文件。校验值保证完整性，不证明提供者可信。

不包含源码、`.git`、运行锁、账号授权密文及其他凭据存储、插件配置或连接器配置。**这不是秘密扫描或自动脱敏保证**：用户写进聊天、附件和命令输出／日志的秘密无法自动可靠识别，备份仍可能含秘密，应当作私有资料保存，分享前逐项审查。

恢复必须指定现有父目录和一个**不存在的新目录名**。先校验并预览，再确认写入；不覆盖已有工作区，不自动打开项目或调用模型。恢复后的记忆默认关闭且自动整理停用；任务验收记录只作历史，需重新验证。会话附件引用重建到新位置，原正文保留；旧机器的代码回滚检查点不激活。请阅读新目录的 `RESTORE-REPORT.txt` 后再使用。

本功能不是代码仓库备份，源码需另外管理。独立开发目录的私有执行数据不自动并入原工作区备份，应单独保管。

## 独立任务开发目录

在 **工作台 → 持久任务与验收 → 任务卡 → 独立目录开发** 预览本地已提交基准并确认创建。创建本身不调用模型；显式选择模型和任务说明，再点击启动。

- 首版支持完整普通非裸仓库；仓库子目录、已有 linked worktree 等不支持场景会明确拒绝。
- 代码来自已提交的本地基准。原工作区未提交／未跟踪文件、个人 `.sakura` 数据不会复制；已经提交到 Git 的秘密不保证自动剔除。
- 使用应用私有 Git common directory（公共元数据与对象库）和真实 linked worktree，不共享原仓库的 Git common directory，也不登记到原仓库的 worktree 列表。独立目录内可以用 Git 识别该 worktree；原仓库 HEAD 和 index 不变。
- 默认位于 `~/.sakura/worktrees/<repository-id>/<id>/tree`，私有记录在同级 `data`。每个任务使用独立 harness、会话、审批和验收，默认最多打开两个。主会话历史不会自动发给独立任务。
- 不自动加载仓库插件、hooks、MCP 或连接器，不自动安装依赖。普通工具默认 cwd 为独立目录，但 shell 仍有当前系统用户权限，目录隔离不是安全沙箱。
- 停止、关闭上下文和删除代码目录是不同操作。关闭/重启不会重放任务；进程异常退出留下锁时需确认无写入者后人工检查，不自动删锁。

完成后刷新成果，明确选择普通文本新增／修改／删除，预览并确认整合。目标选中文件必须匹配基准或上次整合内容；冲突就停止，不自动合并或覆盖原有修改。不会自动 stage、commit 或 push。多文件写入不是文件系统级原子事务；失败时保存前镜像和恢复日志，只回滚仍属于本次写入的内容，外部修改不覆盖。

清理前检查未整合成果；有变化时默认拒绝，只有另外勾选放弃才移除。清理保留 `data` 和恢复记录，不删除原项目或无关分支。

## 外接接入向导

在 **设置 → 集成与连接 → 接入向导** 选择本机 MCP、HTTPS MCP 或 HTTP JSON bridge 模板。逐项填写目标和参数，凭据只填写环境变量引用。

“检查配置字段”不启动程序、不访问服务，只检查格式和凭据存在性。确认实际目标后才进行短生命周期诊断，显示传输、握手、能力声明等阶段；无法独立判定的阶段标为 unknown，不猜测成功。

诊断不会注册或启用工具，不调用软件动作、知识搜索或阅读；握手成功不代表知识查询已验证。正在使用的连接不被诊断替换。报告使用脱敏固定字段，不回传密钥、原始错误正文或服务自报描述。保存配置也不会连接；需要继续在原连接卡明确连接、确认启用能力。

本机程序须已安装，向导不下载软件、执行安装器或把密钥放进命令参数。所有管理、预览和下载接口仅本机操作员可用，不向手机分享或访客开放。
