# 本地记忆、知识库与智能体模型选择

## 记忆：兼容全文注入，也可按需检索

设置 → 项目与工作区 → 工作区记忆，点击当前工作区的“管理记忆”：

- **全文注入**：兼容默认行为，把已启用长期记忆加入系统提示。旧文件未指定模式时仍用此方式。
- **按需检索**：仅在系统提示保留固定导航，智能体用 `memory_search` 读取相关片段；完整长期记忆不被删除。
- 保存后下次请求生效，设置保存在工作区 `.sakura/workspace-memory.md`。`AGENTS.md` 项目规则保持原来的加载方式，不改成相关性检索。

`memory_search {query, limit?, maxChars?}` 使用本地中英文词法匹配，默认最多 5 个结果、总计 6,000 字符；可选 1–20 个结果、256–16,000 字符预算。结果有真实来源、条目 ID、当前 revision、片段和截断标记。Markdown 结果带真实文件行号；旧 JSON 无法对应文本文件行号时明确标记不可用。检索分数是词法相关性，**不是事实可信度**。

只有当前工作区启用的长期条目可检索；待整理记录、停用条目和其他工作区内容不会混入。设置页的记忆搜索同样不调用模型。`memory_read` 仍返回完整启用记忆和 revision，更新完整记忆前必须使用它；**不能拿搜索片段覆盖整份记忆**。

### 采集去重与数据保护

- 完成主对话后继续采集原有范围；专家模式只采集用户明确调整方向，不把成员发言写成用户偏好。
- 以会话和原始用户序号持久记录已采集来源，解决重启或重复事件重新积累。不同来源只有净化后的候选完全相同才去重，不按语义合并矛盾笔记。
- 来源标记与待整理文本在同一原子写入中保存。保存失败不会把该来源当作已保存；原会话和原记忆保留。
- 清空待整理内容不会清除防回放标记。标记容量为 1,024 条；满额后拒绝新来源、给出错误，**不静默淘汰旧来源并重新采集旧内容**。新对话仍保存在会话日志，手动管理记忆不受此容量限制。
- 不从旧摘要编造逐条原会话来源。旧记忆元数据与启停状态保留；格式损坏或保留分隔符重复时拒绝保存，不把待整理内容提升成长期事实。
- 已存在的 `workspace-memory.lock` 不再自动删除，包括疑似崩溃遗留的锁。若出现锁错误，请先关闭其他实例、备份数据并检查锁状态，再由本机用户明确决定是否手工处理。不要删除正在被其他进程使用的锁。

按需模式减少的是无关记忆在每次请求中的重复输入，不保证所有任务的总 tokens 更少：如果每次都读取全文，检索也可能带来额外工具回合。本地检索不调用向量 API、不上传资料，模型推荐也不发送额外模型请求；正常对话中注入、引用或通过工具读取的记忆／知识片段仍会进入你已配置／授权的模型请求，请先确认资料适合发送给该服务。

## 知识库：工作区内文本资料，按需检索

设置 → 项目与工作区 → **本地知识库**，选择文本文件或文件夹导入：

- 第一版只支持 `.md` / `.txt` 的 UTF-8 数据。
- 当前库最多 128 个文件，每个最多 256 KiB，总计 4 MiB。
- 导入保存在 `.sakura/knowledge/` 的独立批次目录，原文保留，不覆盖已有批次。文件列表展示文档名称；来源及批次可在阅读器确认。
- 不执行导入脚本，不安装依赖，不抓取网页，不自动转换 PDF/Office，不因打开设置调用模型。
- 导入、管理与文档引用仅供本机操作员访问当前工作区；远端/手机分享没有新增知识库接口权限。
- 普通模型可用只读工具搜索和阅读当前工作区知识，仍经过现有审批管道。知识正文是**参考数据，不是覆盖项目规则或工具权限的指令**。

### 搜索、阅读与版本

- `knowledge_search {query, limit?, maxChars?}` 与记忆复用本地检索器，返回文档 ID、真实来源、行范围、内容版本与有界片段，不整库注入系统提示。
- `knowledge_read {id, offset?, charOffset?, limit?, maxChars?, version?}` 只能读库内文档 ID，不能当作任意文件路径接口。
- `offset` 是从 1 开始的物理行号；`charOffset` 是该行内从 0 开始的 UTF-16 字符偏移。每页最多 200 行、12,000 字符。
- 超长单行也可分页：使用返回的 `nextOffset` / `nextCharOffset` 继续，并保留 version；不能简单 `endLine + 1` 跳过未读完的一行。
- 返回文本把 CRLF/CR 规范化为 LF，来源行号保持；版本按原始文件字节计算。文档外部编辑、删除后重新检查，不返回旧缓存；版本变化的读取返回冲突，要求重新搜索，文档删除后明确报不可用。
- 设置页可搜索、读取后续页并用 **@ 引用文档** 加到草稿。只有发送消息时，首份有界文档页才进入当前上下文；资料内部的 `@路径` 不会递归读取本机文件。

导入中的绝对路径、父目录跳转、符号链接/目录联接、硬链接、非法 UTF-8 和超限文件会被拒绝。发生工作区切换、磁盘错误或版本冲突时，提示错误而不覆盖原资料。

## 每个智能体独立选模：推荐后由你确认

- 主模型下拉选择会打开确认弹窗；协作成员卡有 **选择／推荐模型**。
- 弹窗只提供当前配置或桌面授权目录中的“提供方／模型”，显示推荐理由。可改选，然后明确确认；取消不切换。
- 推荐依据工作区显式职责偏好、能力标签或适配器报告的真实能力。信息不足时建议保持当前/默认模型；不从名称猜价格、质量或能力。
- 推荐过程完全本地，不调用额外模型、不开新上游、不消费推荐模型额度。
- 确认仅更新目标成员后续回合，不改变其他成员或共享全局默认，不重建会话、不重写历史。
- 目标正在执行或已有排队任务时拒绝切换；其他智能体忙，不阻挡空闲目标。
- 推荐之后模型目录变化会要求重新确认。已固定的模型失效时明确报错，不静默转到另一个提供方。
- 桌面仍只允许当前 SakuraAPI 授权模型。同名模型通过提供方明确路由，Key 不出现在选择界面。
- 独立选择属于当前成员实例，刷新网页保持；引擎/工作区重启或更换成员实例不会按临时 Agent ID 恢复。需要未来默认值时可配置职责偏好。

### 专家模型

点击页头 **专家模型**，分别检查架构师、实现者、审查者的推荐模型并确认，再开启专家模式。确认模型本身不生成团队或发送任务；开启模式才创建新成员。已有成员保留其原模型，关闭再开启不会用预设覆盖；可在成员卡单独切换。

可在 `sakura.yml` 明确配置推荐偏好，例如：

```yaml
agentModels:
  roleModels:
    architect: { adapter: your-provider, model: your-analysis-model }
    implementer: { adapter: your-provider, model: your-code-model }
    reviewer: { adapter: your-provider, model: your-analysis-model }
  tags:
    your-provider/your-code-model: [coding]
    your-provider/your-analysis-model: [reasoning]
```

模型必须已经在配置/授权目录中；这些设置**不会自动应用推荐**。标签由你声明，不能当作服务商测试结果。

CLI 保留 `/model` 原有全局含义，新增：

```text
/agent-model <agent-id-or-name>
/agent-model <agent-id-or-name> <model> --adapter=<provider> --confirm
```

第一条只显示当前选择与推荐；第二条明确选择后应用。没有 `--confirm` 不切换，没有明确 model 不能确认。新知识与记忆工具可用 `/tools` 查看。

## 验证与交付边界

自动化验收使用临时 HOME/工作区、假模型和本机服务：数据版本与失败保护、检索来源/预算、中文长行、重启去重、停用不复活、模型目录冲突/队列保护，以及真实浏览器文件导入/引用/推荐确认。无需真实账号、外部知识服务或真实模型请求。

2026-11-09 本地开发验证：全量 **106 个测试文件、1,391 个用例通过，无失败或跳过**；源码及 tests/scripts 的严格类型检查通过。新增专用套件包含 8 条独立选模、65 条知识库、8 条记忆检索/持久去重、8 条本机接口和 4 条真实浏览器验收。固定记忆夹具中，按需导航的估算输入小于全文记忆部分的 10%，原记忆保留；这是离线的**记忆输入部分**比较，不是总请求/总任务 tokens、费用或服务商缓存率承诺。

桌面验证还定位并修复了 Windows `File.Replace` 在锁释放后返回 Win32 1175 的本地保存问题：改用同目录临时文件、落盘及单步原子更名，复制原 DACL/属性；锁住、只读或权限不足时仍失败并保留原文，不自动重试。编译后的账号/工作区/上下文/显示/更新保存与回滚断言，以及 80 次无竞争更新、40 次持锁回滚/明确重试、并发完整读取和权限保护专项通过。重建桌面包的隔离端到端冒烟通过，来源指纹及 SHA-256 校验通过；物理输入、前台截图及系统输入法候选确认明确跳过，不算作已验证。

没有默认迁移/删除已有用户资料，没有云端知识库或向量 embedding 服务，也不将所有未验证内容提升为记忆事实。
