# 启动、切换与工具图标

## 就绪后再显示工作区

桌面启动器先绘制内置樱花品牌与不定进度动画，同时校验运行引擎、加载工作区并准备专用浏览器。浏览器窗口先隐藏；本机页面通过现有受保护的 `/api/desktop/window` 接口发送 `ready`，仅表示已经建立 Web 加载表面，不表示历史或模型请求完成。原生启动器随后交给这个加载表面，不把 Chromium 默认空白页当作就绪。

启动品牌有轻微呼吸的樱花、缓慢环绕的四片花瓣和往返进度光条；Web 加载内容轻盈入场，当前工作区就绪后以约 240ms 淡出并揭开主界面。没有为了播放完整动画而添加最低启动等待时间。

Web 页面加载层等以下当前连接的数据就绪后才揭开主界面：已认证连接及当前工作区快照、当前会话历史、命令目录初次读取、本机账号初次同步结束、文档／字体及已使用图片资源。无需等待模型任务或后台专家全部结束，未提交的实时输出不会被旧磁盘数据覆盖。可选目录或装饰图片加载失败不阻塞整个工作区，账号同步错误仍由既有账号界面回显。

会话读取失败时保留加载层和错误，可明确重新连接；长时间等待显示重试入口，不生成假的完成百分比，不删除历史或重发任务。浏览器／引擎无法启动的错误由原生启动器明确显示。远端访问仍需原来的操作员／访客认证，登录对话框不被加载层遮住。

## 切换时保留上一页

切换会话、只读历史、工作区或服务重启时，保留上一页已经显示的内容快照，只在当前页面内存中存在。它不接收指针／键盘交互，并从辅助技术树排除；真实目标内容读取完成后一次性替换，不清空到欢迎页再等待。加载期间文字草稿仍可编辑，发送和旧内容操作禁用；未发送附件仍按原规则在真正的会话／工作区切换时移除，防止误投。

历史读取按连接、工作区、会话和递增请求版本核对；迟到的历史／切换成功响应不能覆盖更新的选择。失败时保留上一页并提供「重试读取」，不自动重发修改请求。回合结束同步历史仍保留实时专家卡和相同回答的正在进行／短时复制反馈。

读取期间只让提示中的樱花旋转，上一页保持原位置不动；目标数据完成后，旧画面向上轻移并淡出，新会话从上方 8px 处归位淡入，交接约 240ms。新页面的数据／交互就绪不等待动画，输入区不参与位移，读取说明在对话区显示而不撑高输入框。连续切换会取消旧动画再捕获当前页面；切到设置／工作台或动态启用「减少动态效果」会立即清理离场画面，不留下遮罩或半透明内容。

## 对齐与图标

- 专家展开／收起共用标题行的高度、内边距和箭头宽度；正文出现在其下方，不改变标题行自身对齐。
- 展开侧栏与侧栏恢复入口共用相同樱花 SVG、36px 图标容器、圆角、边框和顶部位置。窄屏可隐藏品牌副标题，但图标不换样式。
- 工具卡、审批卡、独立记录阅读器和工具目录使用 16px 内置 SVG。读写、搜索、命令、浏览器、电脑操作、记忆、计划和成员通信按实际工具名区分；第三方工具按已注册能力或插件／MCP 图标安全回退。名称不是 SVG、HTML 或外部图片地址。
- 最大化／还原使用真实原生客户区和 `IsZoomed` 状态同步浏览器，随后合并一次原生复核；不会重挂浏览器、刷新页面或清空草稿。
- Web 遵循 `prefers-reduced-motion`，原生启动画面只读取 Windows `SPI_GETCLIENTAREAANIMATION`；禁用动画后显示静态品牌，不修改系统偏好。
