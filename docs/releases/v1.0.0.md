# SakuraCode v1.0.0

将此前 0.7.3–0.7.7 的桌面体验与可靠性改进一并发布为 1.0.0。

## 重点修复

- 持续运行的 HTML 预览等后台服务不再阻止只读影响预览、编辑重发或「只回滚对话」。原会话、项目代码和后台任务保留，编辑另存分支后生成一次。
- 「只回滚代码」和「对话与代码一起回滚」仍受后台任务及文件冲突保护。后台任务结束后须刷新预览、重新选择范围并确认，不复用过期确认。
- 会话日志成功写入后才进入模型上下文；磁盘写入失败不会带入失败消息或已回滚附件。
- 删除当前会话清理待发送附件并保留文字草稿；迟到响应不覆盖新会话草稿或专家状态。
- 修复桌面浏览器尺寸漂移的原地恢复；不刷新页面、不重建浏览器、不丢失草稿。

## 自 v0.7.2 以来的更新

- 任意文件附件、消息编辑与回滚、专家共享上下文、长对话折叠，以及每轮 token／耗时统计。
- 默认 Windows DPAPI 加密记住授权；账号、模型 Key、VIP、订阅余量分开显示与管理。
- 可配置失败重试、Skill 导入、分类 `@` 引用、工作区长期记忆和插件市场。
- 分类设置、自适应可调宽面板、托盘恢复、轻量动画和自建 HTTPS 更新源。

## 下载与使用

- **普通桌面使用：下载 `SakuraCode Desktop.exe`**，或解压 `SakuraCode-1.0.0-win-x64.zip` 后双击桌面版。ZIP 同时包含独立 CLI 引擎、使用说明和两份 EXE 校验文件。
- 需要 Windows 10/11 x64、系统 .NET Framework 4.8，以及已安装的 Chrome 或 Edge；运行不需要 Node/npm。
- 更新前先完成任务并退出旧程序，备份旧 EXE，再核对配套 SHA-256。只替换程序和说明文件，**不要删除 `%LOCALAPPDATA%\SakuraCode\Desktop` 或项目 `.sakura`**。
- 当前构建未签名，Windows 可能提示未知发布者。SHA-256 用于校验下载内容，不能代替可信发布者签名；程序不会静默安装更新。

## 验证范围

- 全量测试、源码及测试／脚本严格类型检查，以及隔离 Windows 桌面冒烟；后台持续运行下的编辑／对话回滚和代码恢复保护均有真实 HTTP／Chromium 回归覆盖。
- 自动化使用合成账号和本地模型响应，不读取或上传真实账号与对话。物理中文 IME、原生焦点／窗口手势、多 DPI 实际交互及 Explorer 实体拖放仍需人工验收，不将 CDP 操作等同物理输入。
