# SakuraCode v1.1.2

本次将本地 1.1.1 候选中验证的桌面匿名使用统计整理为 1.1.2，保留 1.1.0 的启动与会话切换体验，不改变授权、审批、模型调用或现有账号与项目数据的保存规则。1.1.1 未发布为 GitHub Release。

## 新增与改进

- **默认自动记录**：没有统计偏好时，启动会自动记录并在后台发送，无需勾选或保存。设置 → **通用与外观 → 匿名使用统计** 不再提供“允许发送匿名启动和使用次数”的勾选框，高级连接设置保留停止与清理按钮。已有明确关闭的偏好或空应用 ID 仍会保留；关闭或应用 ID 为空时，不生成安装标识、事件或采集请求。
- **可配置接收端**：默认地址为 `https://web.mcylyr.cn/api/collect`，公开应用 ID 为 `00f1f158e0bf1d00e84fd321`。允许修改 HTTPS 地址和应用 ID；HTTP 仅允许本机测试。界面显示已保存的接收地址，修改服务或 ID 会清理旧待发数据并重建随机身份。
- **仅统计启动与真实使用**：只记录 `app_start` 和窗口可见、有焦点时的真实用户交互 `active`；活跃事件按五分钟合并，使用单调时钟限频并按 Asia/Shanghai 日期处理跨天。切换工作区不重复创建采集器或统计启动，从托盘恢复不算新的进程启动，不用后台空闲心跳冒充使用。
- **最小字段**：事件仅含随机安装标识、运行会话标识、事件 ID／类型／时间、软件版本、平台和采集协议版本，不发送账号、密钥、聊天、代码、文件名或项目路径；接收服务器仍可见连接 IP。
- **独立持久化**：统计偏好和有上限的待发队列保存在 `%LOCALAPPDATA%\SakuraCode\Desktop\usage-statistics`，跨工作区、随机端口及重启保留，不写入账号文件、通用设置文件或项目数据。
- **可靠重试与停止**：失败采用有上限的后台退避，重试复用原事件 ID，HTTP 200 须附完整确认才移除批次；修复发送中发生交互时可能丢失后续重试唤醒的竞态。关闭后清理本机匿名标识和待发队列并中止在途发送；迟到响应不能恢复旧状态，退出不等待同步上报。
- **权限与诊断**：仅本机操作员可读取或修改统计偏好，只读访客的 REST／SSE 状态不含统计设置；网络和保存故障使用脱敏提示，不影响模型任务。保存连接设置不覆盖既有关闭偏好，停止统计时保留未保存的地址／ID 草稿。

关闭统计不能撤回已发出的请求或删除接收服务器上的历史数据。仅使用可信接收服务；公开应用 ID 不是管理员凭据。此版本不引入外部统计 SDK，不添加首页服务标识或宣传。

## 下载与升级

- **普通桌面使用：下载 `SakuraCode Desktop.exe`**，或解压 `SakuraCode-1.1.2-win-x64.zip` 后双击桌面版。ZIP 包含独立 CLI 引擎、使用说明和两份 EXE 校验文件，配套 ZIP SHA-256 可校验归档。
- 需要 Windows 10/11 x64、系统 .NET Framework 4.8，以及已安装的 Chrome 或 Edge；运行不需要 Node/npm。
- 先完成任务并退出旧程序，备份旧 EXE，核对下载文件的 SHA-256 后仅替换程序和说明文件。**不要删除 `%LOCALAPPDATA%\SakuraCode\Desktop`、项目 `.sakura` 或自定义会话目录**。从没有统计偏好的旧版升级时会默认启用；曾明确关闭的统计偏好不会被升级覆盖。
- 修改源码或推送 GitHub 不会更新已安装的旧 EXE。当前构建未签名，Windows 可能提示未知发布者；SHA-256 不能代替可信发布者签名，更新仍由用户手动安装。

## 验证与已知边界

- 完整回归覆盖采集器、独立存储、桌面宿主、REST／SSE 权限、设置界面和真实浏览器交互；源码及测试／脚本使用严格类型检查。GitHub 发布工作流要求全部测试通过且没有跳过，再生成引擎、桌面程序、ZIP 与校验文件。
- 原生统计专项使用独立数据目录和本机回环采集器，引擎入口前的测试预加载仅将默认采集请求路由到回环地址，验证无需配置的自动启动记录、确认移除、重启身份复用、关闭时中止发送及清理。测试不发送生产统计事件；未使用真实账号或物理鼠标／键盘输入。
- **联网验收尚未完成**：本次不将回环测试视为生产采集服务或 IPv6 网络的连通性验收。
- **既有桌面冒烟限制仍在**：当前 Windows 环境的完整桌面冒烟受账号／外观保存预检查中的 `File.Replace` 故障影响。本次没有修改或绕过该保存实现，也不声称已完成这一轮完整桌面验收。保存失败时保留原数据、查看错误并明确重试，不通过清空配置或授权掩盖失败。
- 原生启动绘制／CDP 自动化不等于物理托盘点击、系统中文 IME、多显示器 DPI 或真实官网授权验收；1.1.0 的历史用户实测也不替代 1.1.2 的这些检查。
