# SakuraCode v1.1.3

本次修复桌面版点击“查看发行说明与下载”没有可见响应的问题，接入官网下载站，保留 v1.1.2 默认匿名统计、已有关闭偏好和现有账号／项目数据保存规则。

## 修复与改进

- **桌面链接使用系统浏览器**：官网下载页及已验证的自建发行说明／下载链接通过本机桌面接口交给系统默认浏览器，绕过内嵌应用窗口不可见的新标签。普通 Web 版仍使用正常的新标签链接，不在 Web 服务器机器上打开浏览器。
- **官网下载入口**：默认“查看发行说明与下载”打开 **https://download.sakuraapi.top/**。尚未检查、没有新版或版本检查失败时也可访问；默认仍使用本项目 GitHub Releases 判断最新稳定版。下载首页是 HTML，不是客户端 JSON 版本清单；已有自建清单地址不会被覆盖。
- **明确反馈与手动备用入口**：点击后显示“正在打开”和系统打开请求的结果；系统浏览器不可用时显示错误，保留经过验证的地址供复制／手动打开。防止重复点击并支持键盘 Enter，不自动重试、下载执行或安装。系统打开回执不等于网页加载或下载成功。
- **链接与权限校验**：本机操作员接口仅允许固定官网下载页或当前检查结果里的可信地址，自建直接下载仍要求同源地址、有效 SHA-256 和大小声明；拒绝任意地址、附加字段、过期结果、未登录、只读访客和远端调用。更新源改变后清理旧提示，迟到响应不恢复旧地址；原始系统错误不泄露到界面。
- **按钮文字可读**：修复下载按钮悬停时被通用链接样式覆盖文字颜色的问题，明暗主题保持对比度；复制失败不会伪称成功。
- **统一版本**：包清单、CLI、Web、微信客户端标识统一为 1.1.3，Windows 桌面 EXE 文件版本为 1.1.3.0；依赖版本不变。

更新行为与自建清单说明见 [桌面更新说明](https://github.com/Guyao146/SakuraCode/blob/v1.1.3/docs/desktop-updates.md)。

## 下载与升级

- **普通桌面使用：下载 `SakuraCode.Desktop.exe`**（可重命名为 `SakuraCode Desktop.exe`），或解压 `SakuraCode-1.1.3-win-x64.zip` 后双击桌面版。ZIP 包含独立 CLI 引擎、使用说明和两份 EXE 校验文件，配套 ZIP SHA-256 可校验归档。
- 需要 Windows 10/11 x64、系统 .NET Framework 4.8，以及已安装的 Chrome 或 Edge；运行不需要 Node/npm。
- 先完成任务并退出旧程序，备份旧 EXE，核对下载文件 SHA-256 后仅替换程序和说明文件。**不要删除 `%LOCALAPPDATA%\SakuraCode\Desktop`、项目 `.sakura` 或自定义会话目录**。已有账号、设置和历史数据保留；没有统计偏好时继续默认启用，曾明确关闭的偏好不被覆盖。
- 下载站镜像可能滞后，下载前核对 **SakuraCode、1.1.3 及对应 SHA-256**；不要将旧镜像或站点其他配套工具当成本次发行包。GitHub 发布不等于下载站镜像已同步。
- 修改源码或推送发布不会替换已安装的旧 EXE。当前构建未签名，Windows 可能提示未知发布者；SHA-256 不能代替可信发布者签名，更新由用户手动安装。

## 验证与已知边界

- 完整回归覆盖版本一致性、更新清单、REST／SSE 权限、真实浏览器点击、键盘、复制失败、明暗主题悬停和既有功能；源码、测试及脚本使用严格类型检查。发布工作流要求全部测试通过且没有跳过，再生成桌面程序、引擎、ZIP 和校验文件。
- 原生更新链接专项使用独立数据目录、合成更新清单和引擎入口前的离线预加载；核对真实编译 EXE 的点击到系统浏览器命令分发、失败／重试、隐藏标签消除、重启与默认入口。系统浏览器命令被测试夹具拦截，不打开或检查用户的真实浏览器，不将分发通过声称为公网页面已加载。
- 原生匿名统计专项仅将默认采集请求路由到本机回环采集器，检查自动启动记录、确认移除、重启、关闭与清理；启动绘制单独验证。测试不发送生产统计事件，不使用真实账号或物理鼠标／键盘输入。
- **既有完整桌面冒烟限制仍在**：当前 Windows 环境曾在账号／外观保存预检查遇到 `File.Replace` 故障；本次没有修改或绕过该实现，也不声称已完成所有桌面端到端验收。保存失败保留原数据，查看错误后明确重试，不通过清空配置／授权掩盖失败。
- 系统默认浏览器真实启动、公网下载站／附件访问、生产统计服务和 IPv6 连通性需要单独的联网验收；离线 CDP／回环／原生绘制不替代物理托盘、系统中文 IME、多显示器 DPI 或真实官网授权验证。
