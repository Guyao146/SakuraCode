# SakuraCode v1.1.0

本次聚焦桌面启动、会话切换和多智能体界面的显示体验，保留现有授权、审批、模型调用与数据存储规则。

## 新增与改进

- **启动动画**：原生窗口立即绘制樱花呼吸、四片花瓣缓慢环绕和不定进度光条；内嵌 Web 加载表面接管后，等待当前工作区、会话历史及必要资源就绪，再平滑淡出加载层。没有为播放动画而增加最低等待时间。
- **切换会话动画**：读取目标期间保留上一页的只读画面，目标内容就绪后使用约 240ms 的淡入淡出与轻微位移交接，不先闪现欢迎页。读取失败保留上一页并提供明确重试，不自动重发任务。
- **快速切换保护**：连续切换清理上一段动画；历史请求和会话操作的迟到响应不能覆盖更新的选择。文字草稿、复制反馈和实时专家卡保留；未发送附件仍按原规则在真正切换会话／工作区时移除，防止误投。
- **稳定标题与品牌**：专家展开／收起共用固定标题行高度、内边距和箭头宽度；展开侧栏与恢复入口统一樱花 Logo 的大小、圆角、边框和顶部位置。
- **本地工具图标**：工具卡、审批卡、独立记录阅读器和工具目录采用小型内置 SVG；未知工具、插件和 MCP 安全回退，不从工具名称加载 HTML 或外部图标。
- **最大化与还原**：使用真实原生客户区与 `IsZoomed` 状态同步浏览器，并合并原生复核，不重挂 Chromium、不刷新页面、不清空草稿。
- **减少动态效果**：Web 遵循 `prefers-reduced-motion`，原生启动画面只读取 Windows 动画偏好；偏好变化时及时清理过渡，不修改系统设置。

行为说明见 [启动、切换与工具图标](../desktop-motion-icons.md)。

## 下载与升级

- **普通桌面使用：下载 `SakuraCode Desktop.exe`**，或解压 `SakuraCode-1.1.0-win-x64.zip` 后双击桌面版。ZIP 包含独立 CLI 引擎、使用说明和两份 EXE 校验文件，配套 ZIP SHA-256 可校验归档。
- 需要 Windows 10/11 x64、系统 .NET Framework 4.8，以及已安装的 Chrome 或 Edge；运行不需要 Node/npm。
- 先完成任务并退出旧程序，备份旧 EXE，核对下载文件的 SHA-256 后仅替换程序和说明文件。**不要删除 `%LOCALAPPDATA%\SakuraCode\Desktop`、项目 `.sakura` 或自定义会话目录**。
- 修改源码不会更新已安装的旧 EXE。当前构建未签名，Windows 可能提示未知发布者；SHA-256 不能代替可信发布者签名，更新仍由用户手动安装。

## 验证与已知边界

- 完整回归、源码及测试／脚本严格类型检查，并在隔离 Windows 环境验证原生启动绘制、真实客户区尺寸和会话过渡；自动化使用合成账号、本地响应和独立数据目录。
- 原生绘制测试不等于捕获启动全过程的每一屏；CDP／原生 API 自动化不等于物理托盘点击、系统中文 IME、多显示器 DPI 或真实账号官网授权验收。
- **当前原生验收限制**：发布前的 1.1.0 隔离桌面冒烟在合成账号保存步骤失败，尚未完成当前发行产物的整套原生验收；此前的界面候选曾通过非物理输入模式的完整冒烟。已观察到 Windows `File.Replace` 间歇保存失败（错误 1175），本次没有修改或绕过生产保存实现，也不将单次通过视为该问题已修复。发行产物先保持草稿，待进一步核验。保存失败时应保留原数据、查看界面错误并明确重试，不通过清空配置或授权来掩盖失败。
