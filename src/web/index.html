SakuraAPI 账号连接

通过官网客户端接口连接账号，同步资料、VIP、余额和订阅，再前往模型设置选择已有 Key 或确认模型分组创建新 Key。

使用一次性授权码与 S256 PKCE 获取独立客户端账号凭据，不读取密码或浏览器登录令牌，不自动创建 Key。客户端可查询本人 Key 并按确认的分组创建 Key；账号凭据不用于模型调用。连续 5 天未使用需重新授权，后台刷新不作为活跃心跳。退出单独撤销客户端会话，不删除模型 Key。

SakuraAPI 账号与模型调用

模型调用 Key

连接账号不会自动选择 Key。选择已有 Key 后校验所有权、状态、有效期与额度，完整密钥仅在后台使用。

选择模型分组并创建新 Key

仅列出普通模型分组，不列出订阅分组；倍率四舍五入显示两位小数，实际计费以官网为准。可选 1–32 个，列表顺序为优先级。创建前需确认；失败需明确重试，不自动重复创建。

确认创建模型 Key

此次创建不单独限制总额度，走账号余额或订阅。完整 Key 不显示在页面中。创建后校验并选择，可能因网络或保存失败需要明确重试。

上游站点

普通 CLI/Web 可配置多个模型站点。桌面专用版仅使用 SakuraAPI 官网授权。

桌面版上游固定为 https://api.sakuraapi.top/v1。授权 Key 仅在后台使用，不允许手填地址或 Key；模型只来自官网授权 Key 的可用列表。

不勾选保存，只在本次运行中使用；不会清除当前密钥。清除密钥需要单独勾选。

当前是 Web 服务工作区。模型连接由启动服务的配置管理，浏览器不会修改服务端凭据。

在项目的 sakura.yml 中配置模型，将密钥放入服务端环境变量 SAKURA_API_KEY，然后重启服务。模型、思考能力与权限范围会反映在对话输入框中。
